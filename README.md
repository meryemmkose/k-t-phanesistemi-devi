Kütüphane Yönetim Sistemi Ödevi

Nesne Yönelimli Programlama dersi için yaptığımız kütüphane projesi. 

Sistemde temel olarak kitaplar, bu kitapların kopyaları, kullanıcılar, üyeler ve kütüphane görevlileri var. Üyeler kitap alabiliyor, görevliler de yeni kitap ekleyip işlemleri onaylıyor falan. Bütün sınıfları yazıp Main üzerinden test ettik, konsolda sorunsuz çalışıyor.

Projedeki sınıflar:
- kitap
- kitapKopyasi
- kullanıcı
- Uye
- KutuphaneGorevlisi
- OduncAlma
- Main
